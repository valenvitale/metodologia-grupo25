### git commit -am "mensaje"

# ¿Para qué sirve?
Combinando -a y -m, agrega los cambios de archivos ya existentes y realiza el commit con el mensaje que se encuentra entre comillas. Al igual que el git commit -a, 
no tiene en cuenta archivos nuevos.

# Ejemplo
git commit -am "fix: corregí el archivo git-commit-am.md"
